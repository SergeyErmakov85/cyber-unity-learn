# Справочник: публикация .md с математикой

Подробности к [`SKILL.md`](SKILL.md). Всё здесь описывает реальное поведение кода,
а не пожелания: генератор — `scripts/build-textbook-index.mjs`, рендер —
`src/components/textbook/MarkdownLecture.tsx`, раскраска — `src/lib/katex-options.ts`.

## 1. Куда что ложится

Семь частей учебника. Столбец «Каталог» — куда кладётся файл в исходном репозитории,
«Сегмент» — что появится в адресе `/math-rl/textbook/<сегмент>/<имя-файла>`.

| Сегмент | Каталог | `part_id` | Часть | Темы, по которым узнаётся материал |
|---|---|---|---|---|
| `part-1` | `part-1-limits-series` | `part-1` | I. Пределы, последовательности и ряды | предел, сходимость, ряд, геометрическая прогрессия, дисконтирование, γ, эффективный горизонт, критерий остановки, итерация ценности |
| `part-2` | `part-2-derivatives-gradient` | `part-1b` | II. Производные, градиент и оптимизация | производная, дифференцирование, частная производная, градиент, градиентный спуск, learning rate, цепное правило |
| `part-3` | `part-3-linear-algebra` | `part-2` | III. Линейная алгебра для RL | вектор, матрица, скалярное произведение, норма, собственные значения, SVD, ранг, базис, проекция, обусловленность |
| `part-4` | `part-4-probability` | `part-3` | IV. От вероятности к алгоритмам RL | вероятность, распределение, ожидание, дисперсия, Байес, цепь Маркова, MDP, статистика, оценка параметров |
| `part-5` | `part-5-policy-optimization` | `part-4` | V. Методы оптимизации политик | целевая функция политики, вывод градиента политики, log-trick, REINFORCE, baseline, advantage, Adam, momentum, PPO, клиппинг |
| `part-6` | `part-6-fundamental-rl` | `part-5` | VI. Фундаментальная математика RL | бандиты, UCB, ε-жадность, MDP, возврат, V и Q, уравнения Беллмана, TD, SARSA, Q-learning, eligibility traces, аппроксимация, actor-critic, ML-Agents |
| `part-7` | `part-7-deep-rl` | `part-6` | VII. Глубокое обучение с подкреплением | DQN и его улучшения, обзор алгоритмов, матанализ для DL, MLE и MAP, дифференциальные уравнения |

**`part_id` — это id части на сайте, он НЕ совпадает с номером каталога.** Часть VI лежит
в `part-6-fundamental-rl`, а её `part_id` — `part-5`. Каноническая таблица —
`src/content/textbook/parts.ts`; генератор падает, если значения разошлись.

### Разрешение формулировок пользователя

| Сказано | Куда |
|---|---|
| «в часть V», «в пятую часть» | римская нумерация → `part-5-policy-optimization` |
| «в модуль 5», ссылка на `/math-rl/module-5` | маршрут хаба → часть VI, каталог `part-6-fundamental-rl` |
| «к Беллману», «к PPO», «к градиенту политики» | по теме, см. таблицу выше |
| «на страницу урока 2.2» | материал остаётся лекцией учебника; в урок добавляется связь через `crosslinks.ts` — страницы уроков не наполняются математикой напрямую |
| «в хаб», «в /math-rl» | хаб — краткий обзор в TSX; новый материал идёт в учебник, а в хабе появляется ссылкой (полоса `TextbookStrip` собирается автоматически) |

Если материал не ложится ни в одну часть (например, это не математика, а инженерная
заметка) — скажи об этом прямо и предложи альтернативу вместо того, чтобы класть силой.

## 2. Frontmatter

```yaml
---
id: part-5-05                     # <part_id>-<NN>, уникален по всему пособию
title: "Глава 5. Сердце RL: Уравнения Беллмана"
part: "VI · Фундаментальная RL"   # человекочитаемая подпись части
part_id: part-5                   # id части НА САЙТЕ (см. таблицу)
order: 5                          # порядок внутри части
mindmap_node: "Уравнения Беллмана" # подпись узла mind map или отсутствует
difficulty: intermediate          # beginner | intermediate | advanced
tags: ["bellman", "value-function", "dp"]
hub_url: "https://rl-cuber-unity-code.com/math-rl/module-5#глава-5-сердце-rl-уравнения-беллмана"
hub_anchor_canonical: "глава-5"   # короткий якорь, если он есть в хабе
enf_mode: learning                # learning | publication
discipline: rl
duration: 90                      # минут чтения
date: 2026-08-09
status: ready                     # empty | draft | ready
---
```

Что проверяет генератор и на чём останавливает сборку:

- нет `title` — ошибка;
- `part_id` не совпал с каталогом — ошибка;
- `status` отсутствует или `empty` — ошибка (`draft` — предупреждение);
- дубль `id` — ошибка;
- относительная ссылка на несуществующий `.md` или несуществующий якорь — ошибка;
- `\class{`, `\textcolor{`, `\color{` в тексте — ошибка;
- число разделов в каталоге не совпало с `sections:` в `index.md` части — предупреждение.

`hub_url` и `hub_anchor_canonical` нужны только если у материала есть краткая версия
в хабе `/math-rl`. Если её нет, оставь `hub_anchor_canonical` пустым — тогда якорем
станет `slugify(title)`, и ссылка «Краткая версия в хабе» приведёт в начало части.

### slugify

Одна на весь сайт (`src/lib/slug.ts`), от неё зависят все якоря:

```
lower → [^\wа-яё]+ заменить на "-" → обрезать "-" по краям → первые 60 символов
```

Менять её нельзя: ссылки останутся валидными, но начнут вести в пустоту.

## 3. Что поддерживает рендер

| Конструкция | Как отрисуется |
|---|---|
| `$…$`, `$$…$$` | KaTeX; макросы ролей дают цвет |
| `> [!definition\|theorem\|lemma\|corollary\|proof\|example\|remark\|warning\|intuition]` | карточка с акцентом и глифом; заголовок может содержать математику |
| ` ```python `, ` ```csharp ` | подсветка через `CyberCodeBlock` |
| ` ```mermaid ` | диаграмма, библиотека грузится лениво |
| таблицы GFM | скроллятся по горизонтали |
| `[текст](../part-1-limits-series/05-value-iteration.md#якорь)` | внутренняя SPA-ссылка на лекцию |
| `[текст](https://rl-cuber-unity-code.com/courses/1-3)` | внутренняя ссылка без перезагрузки |
| `` `Assets/ML-ENVIRONMENTS/.../RollerAgent.cs` `` | ссылка на GitHub, если путь есть в `_meta/unity-bridge.md` |
| прочие относительные пути (`../examples/…`, `_meta/…`) | ссылка на GitHub исходного репозитория |

Заголовок `# H1` из тела убирается: его рисует страница. Разделы — с `##`.

Не поддерживается и требует переделки: сырой HTML, `<style>`, картинки с внешних
адресов, окружения `align`/`equation` (нужен `aligned`), `tikzpicture`.

## 4. Палитра

Цвета живут в `src/styles/enf-math.css` и больше нигде. Значения — тёмная половина
палитры ENF, контраст на фоне сайта проверен (от 6.1:1 до 14.6:1 при требовании 4.5:1).

| Роль | Класс | Тон |
|---|---|---|
| переменная | `enf-variable` | `#9BA3D2` |
| функция | `enf-function` | `#E89157` |
| параметр | `enf-parameter` | `#A6E768` |
| оператор | `enf-operator` | `#FFD6FF` |
| цель | `enf-target` | `#D6768B` |
| нейтральное | `enf-neutral` | `#B9C2CC` |

Механика: макрос `\enfVar{x}` разворачивается в `\htmlClass{enf-variable}{x}`
(см. `src/lib/katex-options.ts`), KaTeX вешает класс, CSS даёт цвет. Работает при
трёх условиях сразу — заданы `macros`, `trust` разрешает `\htmlClass`, `strict: false`.
Нарушение любого не даёт ошибки: формула просто станет одноцветной.

Контрольная формула — обязана дать пять разных цветов:

```latex
\enfOp{\mathbb{E}}\left[ \enfTgt{r} + \enfPar{\gamma}\, \enfFun{f}(\enfVar{x}) \right]
```

## 5. Частые ошибки

| Симптом | Причина | Где чинить |
|---|---|---|
| Формулы серые | в тексте `\textcolor`/`\color` вместо макросов ролей | шаг 3 процедуры |
| В формуле виден `\enfVar` текстом | материал попал на страницу мимо `MarkdownLecture` | проверить, что это лекция учебника |
| «Undefined control sequence» | в тексте `\class` (макрос MathJax, KaTeX его не знает) | заменить на макрос роли |
| Страница есть, в оглавлении части нет | не тронут `index.md` части | шаг 6 |
| Узел mind map ведёт не туда | подпись листа в `RAW` не совпала с `mindmap_node` | `src/content/mathMindMap.ts` |
| Ссылка `../…md` даёт 404 | опечатка в пути; генератор поймал бы — значит сборку не перезапускали | `npm run textbook:index` |
| `textbook:check` ругается на расхождение | правка сделана в копии, а не в исходнике | перенести в исходный репозиторий |
| Подписи в mermaid обрезаны | диаграмма отрисована до загрузки шрифта | уже лечится `document.fonts.ready`; если вернулось — смотреть `MermaidDiagram.tsx` |

## 6. Команды

```powershell
npm run textbook:sync     # забрать .md из исходного репозитория + пересобрать индекс и sitemap
npm run textbook:check    # только показать расхождение копий (для CI)
npm run textbook:index    # пересобрать индекс и sitemap без копирования
npm run textbook:audit    # ссылки, маршруты, обе карты, раскраска, мост в код
npm run audit:links       # якоря внутри сайта
npm run build

pwsh C:/Math_for_DS_&_RL/Scripts/check.ps1 <путь к .md>   # проверки ENF в исходном репозитории
```

Путь к исходнику переопределяется переменной `ENF_TEXTBOOK_SRC`, путь к репозиторию
сред Unity — `UNITY_LAB_SRC`.
