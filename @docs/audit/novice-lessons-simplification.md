## Источники и воспроизводимость

- Лаборатория зафиксирована на коммите [`6e11c9944c2602f4083632f51eb5b160c0566364`](https://github.com/SergeyErmakov85/unity-ml-agents-lab/tree/6e11c9944c2602f4083632f51eb5b160c0566364).
- Python 3.10.12, NumPy 1.23.5, PyTorch 2.2.1, Gymnasium 0.29.1, Matplotlib 3.7.5.
- Python ML-Agents установлен из `release_23_tag`; ограничения сверены с официальными `setup.py`. Прежний Release 22 заменён для соответствия лаборатории с Unity-пакетом 4.x.
- Версия Unity лаборатории — 6000.5.4f1. Её готовые скрипты сборки рассчитаны на Windows x64; это явно указано в 1.2 и проекте.
- Код Python на страницах импортируется из `src/content/novice/code/*.py` и скачивается без отдельной копии. Синхронизация RoomBot с ноутбуком: `node scripts/sync-novice-notebook.mjs`; проверка: та же команда с `--check`.
- Навигация берёт названия и порядок из `LEARNING_MAP`; обновлены ссылки из хабов и сгенерированный сборкой MCP-каталог. Неиспользуемые компоненты прежних начальных уроков удалены.

- Дополнительно все 8 страниц проверены при ширине 1440 и 390: оглавление, один квиз, закрытая дополнительная теория, отсутствие горизонтального переполнения. Проверены скачивание полного Python-файла и ответы квиза 1.1.
- В чистом Python 3.10.12 CPU-окружении установлены зависимости курса, ML-Agents и `labrl`: `pip check`, `mlagents-learn --help`, `train.py --help` и `check_inference.py --help` успешны.
