# Create a Complete Interactive Knowledge Mind Map for Reinforcement Learning NPC Development

You are acting as a senior AI architect, technical writer, information architect, UX designer, and educational curriculum developer.

## Primary Objective

Analyze the entire current website, including all pages, articles, tutorials, documentation, code examples, blog posts, videos, downloadable resources, and internal links.

Based on this analysis, create a new standalone page named:

**"Reinforcement Learning NPC Development Knowledge Map"**

The page must serve as the central learning hub for mastering the creation of intelligent non-player characters (NPCs) using Reinforcement Learning.

---

## Content Analysis Requirements

Before generating the page:

1. Crawl and analyze every accessible page on the website.
2. Extract:

   * Topics
   * Concepts
   * Tutorials
   * Examples
   * Tools
   * Frameworks
   * Algorithms
   * Research references
   * Implementation guides
   * Best practices
3. Detect relationships between topics.
4. Identify prerequisite knowledge chains.
5. Identify duplicated content and merge it conceptually.
6. Organize all content into a coherent learning progression.

## Linking Requirements

Every node in the mind map must be clickable.

Each node should link to:

* a relevant page on the website,
* or a specific section within a page,
* or a generated anchor link.

Use deep links whenever possible.

Example:

Node:
"PPO Algorithm"

Link:
"/reinforcement-learning/ppo#advantages"

instead of merely:

"/reinforcement-learning/ppo"
