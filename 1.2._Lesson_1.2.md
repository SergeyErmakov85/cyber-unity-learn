# Урок 1.2. Установка окружения: PyTorch + Unity ML-Agents

В этом уроке мы развернём полное окружение для Deep Reinforcement Learning: Anaconda с Python 3.10, изолированную conda-среду, PyTorch с поддержкой CUDA, Unity 6 с пакетом ML-Agents и VS Code с Jupyter-ноутбуками. Установка ML-Agents выполняется «продвинутым» способом — клонированием официального репозитория через git: так вы получите не только Python-пакеты, но и исходный код тренера, готовые сцены-примеры и конфигурации обучения. Все шаги образуют единую цепочку: от чистой системы до успешного запуска `mlagents-learn --help`. Инструкция актуальна для **ML-Agents Release 22** — последнего стабильного релиза тулкита.

## 1. Установка Anaconda

Мы работаем через **Anaconda** — дистрибутив Python с менеджером окружений conda. Это решает главную проблему урока одним инструментом: ML-Agents принимает только Python 3.10.x, и conda позволяет создать среду с точной версией 3.10.12, не трогая системный Python. Официальная документация ML-Agents рекомендует именно conda.

> Если вам не нужен полный набор пакетов Anaconda (~5 ГБ), можно установить лёгкий **Miniconda** (<https://www.anaconda.com/docs/getting-started/miniconda/main>) — все команды conda в уроке идентичны. Ниже описана установка полной Anaconda Distribution.

### Windows 10/11

1. Скачайте установщик **Anaconda Distribution** для Windows (64-bit): <https://www.anaconda.com/download>.
2. Запустите `.exe`-установщик: *Just Me* → путь по умолчанию (`C:\Users\<имя>\anaconda3`).
3. На шаге *Advanced Options* оставьте настройки по умолчанию: галочку **«Add Anaconda3 to my PATH»** ставить **не нужно** — работать будем через Anaconda Prompt.
4. После установки откройте **Anaconda Prompt** (или Anaconda PowerShell Prompt) из меню «Пуск» и проверьте:

```powershell
conda --version
# conda 24.x.x или новее
```

Чтобы conda была доступна и в обычном PowerShell/терминале VS Code, выполните один раз:

```powershell
conda init powershell
```

Если после этого PowerShell блокирует загрузку профиля, разрешите локальные скрипты: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.

### macOS (M1/M2/M3)

1. Скачайте установщик для **Apple Silicon** (`.pkg`, arm64): <https://www.anaconda.com/download> — не перепутайте с Intel-версией.
2. Запустите `.pkg` и пройдите шаги установщика (путь по умолчанию — `~/anaconda3`).
3. Откройте новый терминал и проверьте:

```bash
conda --version
```

Если команда не найдена, инициализируйте оболочку вручную: `~/anaconda3/bin/conda init zsh` и перезапустите терминал.

### Linux (Ubuntu)

```bash
# Скачиваем установщик (актуальное имя файла — на https://www.anaconda.com/download)
wget https://repo.anaconda.com/archive/Anaconda3-2024.10-1-Linux-x86_64.sh
bash Anaconda3-2024.10-1-Linux-x86_64.sh
```

В диалоге установщика: примите лицензию (`yes`), подтвердите путь `~/anaconda3`, на вопрос про инициализацию (`conda init`) ответьте `yes`. Затем перезапустите терминал и проверьте:

```bash
conda --version
```

Также убедитесь, что установлен git: `sudo apt update && sudo apt install -y git`.

## 2. Создание виртуальной среды conda

Все Python-пакеты курса живут в изолированной conda-среде `mlagents` — это гарантирует воспроизводимость и нужную версию Python 3.10.12 независимо от системного Python. Создадим рабочую папку курса и среду.

**Windows (Anaconda Prompt / PowerShell):**

```powershell
mkdir C:\rl-course
cd C:\rl-course
```

**macOS / Linux:**

```bash
mkdir ~/rl-course && cd ~/rl-course
```

Дальше команды одинаковы для всех ОС — conda сама скачает Python 3.10.12 в среду:

```bash
conda create -n mlagents python=3.10.12
conda activate mlagents
```

После активации в начале строки терминала появится `(mlagents)`. **Все дальнейшие pip- и mlagents-команды урока выполняются только внутри активированной среды** — при каждом новом сеансе терминала не забывайте `conda activate mlagents`.

Проверьте версию Python и обновите базовые инструменты:

```bash
python --version    # Python 3.10.12
python -m pip install --upgrade pip setuptools wheel
```

Полезные команды на будущее: `conda deactivate` — выйти из среды, `conda env list` — список сред, `conda env remove -n mlagents` — удалить среду и начать с чистого листа.

## 3. Установка PyTorch (последняя стабильная, с CUDA)

PyTorch ставим **до** ML-Agents: иначе pip на Windows подтянет CPU-версию по умолчанию, и обучение не будет использовать GPU.

### Windows / Linux с GPU NVIDIA

Ставим последнюю стабильную сборку с CUDA 12.8 (CUDA-runtime входит в состав колеса — отдельно CUDA Toolkit устанавливать не нужно, достаточно свежего драйвера NVIDIA):

```bash
pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu128
```

Проверить версию драйвера: `nvidia-smi`. Актуальную команду под вашу связку ОС/CUDA всегда можно сгенерировать в официальном селекторе: <https://pytorch.org/get-started/locally/>.

### Windows / Linux без дискретной GPU

```bash
pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cpu
```

### macOS (M1/M2/M3)

На Apple Silicon CUDA недоступна; GPU-ускорение обеспечивает встроенный backend **MPS** (Metal), он входит в стандартную сборку:

```bash
pip3 install torch torchvision
```

### Проверка установки

```bash
python -c "import torch; print(torch.__version__); print('CUDA:', torch.cuda.is_available()); print('MPS:', getattr(torch.backends, 'mps', None) and torch.backends.mps.is_available())"
```

Ожидаемый результат: версия `2.x`, `CUDA: True` на машине с NVIDIA GPU (или `MPS: True` на Mac). Если `CUDA: False` при наличии видеокарты — обновите драйвер NVIDIA и переустановите пакет из `cu128`-индекса.

## 4. Установка Unity 6

1. Скачайте и установите **Unity Hub**: <https://unity.com/download>.
2. В Unity Hub: *Installs → Install Editor* → выберите **Unity 6 LTS (6000.x)**. Модули (Android/iOS и т. п.) для курса не нужны.
3. Создайте тестовый 3D-проект (*Projects → New project → Universal 3D*), чтобы убедиться, что редактор запускается.

> ML-Agents Release 22 официально поддерживает **Unity 6000.0 и новее**. Не используйте версии старее Unity 6 — Unity-пакет ML-Agents с ними несовместим.

## 5. Клонирование и установка ML-Agents через git

### 5.1. Клонирование репозитория

Клонируем именно релизную ветку `release_22` — она зафиксирована и протестирована, в отличие от `develop`:

```bash
cd ~/rl-course        # Windows: cd C:\rl-course
git clone --branch release_22 https://github.com/Unity-Technologies/ml-agents.git
```

В репозитории вы получаете: исходный код тренера (`ml-agents/`), низкоуровневый API среды (`ml-agents-envs/`), Unity-пакеты (`com.unity.ml-agents`), готовые сцены-примеры (`Project/Assets/ML-Agents/Examples/` — 3DBall, PushBlock, Crawler и др.) и конфиги обучения (`config/`).

### 5.2. Установка Python-пакетов из клонированного репозитория

Внутри активированной среды `mlagents` устанавливаем оба пакета в editable-режиме (`-e`) — изменения в исходном коде будут подхватываться без переустановки. Порядок важен: сначала `ml-agents-envs`, затем `ml-agents`:

```bash
cd ml-agents
python -m pip install -e ./ml-agents-envs
python -m pip install -e ./ml-agents
```

> **Ожидаемое поведение pip:** установщик может понизить версии `numpy` (до 1.23.x) и `protobuf` (до 3.20.x) — это штатные ограничения зависимостей ML-Agents, не «ломайте» их обратным обновлением. Уже установленный PyTorch с CUDA при этом не затрагивается, так как удовлетворяет требованию `torch>=2.1.1`.

### 5.3. Подключение Unity-пакета к проекту

1. Откройте тестовый проект в Unity 6.
2. *Window → Package Manager → «+» → Add package from disk…*
3. Выберите файл `ml-agents/com.unity.ml-agents/package.json` из клонированного репозитория.

Установка «с диска» гарантирует, что версия Unity-пакета точно соответствует версии Python-пакетов из той же ветки `release_22`. Для проверки откройте сцену `Project/Assets/ML-Agents/Examples/3DBall/Scenes/3DBall.unity` (сам подпроект `Project/` тоже можно открыть через Unity Hub → *Add project from disk*) и нажмите Play — агенты начнут балансировать мячи на предобученной модели.

### 5.4. Проверка Python-части

```bash
mlagents-learn --help
```

Если на экране появилась справка с логотипом ML-Agents и списком опций — Python-часть тулкита установлена корректно.

## 6. VS Code + Jupyter

Дальнейшая работа в курсе организована в VS Code с Jupyter-ноутбуками.

### 6.1. Установка

1. Установите **VS Code**: <https://code.visualstudio.com/>.
2. Установите расширения (⇧⌘X / Ctrl+Shift+X):
   - **Python** (`ms-python.python`),
   - **Pylance** (`ms-python.vscode-pylance`) — ставится вместе с Python,
   - **Jupyter** (`ms-toolsai.jupyter`).

### 6.2. Подключение окружения

1. Откройте папку курса: *File → Open Folder…* → `rl-course`.
2. Ctrl+Shift+P → **Python: Select Interpreter** → выберите интерпретатор **`Python 3.10.12 ('mlagents')`** — VS Code автоматически находит conda-среды в списке.
3. Добавьте ядро Jupyter в среду (в терминале с активированной `mlagents`):

```bash
pip install ipykernel
```

### 6.3. Проверка ноутбука

Создайте файл `check_env.ipynb` (Ctrl+Shift+P → *Create: New Jupyter Notebook*), в правом верхнем углу через *Select Kernel* выберите среду `mlagents` и выполните ячейку:

```python
import torch
import mlagents_envs
from mlagents_envs.environment import UnityEnvironment

print("PyTorch:", torch.__version__)
print("CUDA:", torch.cuda.is_available())
print("ml-agents-envs: OK")
```

Ячейка должна отработать без ошибок и показать версию PyTorch 2.x.

## 7. Финальная проверка работоспособности

Контрольный чек-лист — все команды выполняются в активированной среде (`conda activate mlagents`):

```bash
python --version          # Python 3.10.12
python -c "import torch; print(torch.cuda.is_available())"   # True (NVIDIA) / False (CPU, Mac)
mlagents-learn --help     # справка ML-Agents без ошибок
```

Если `mlagents-learn --help` выводит справку — окружение полностью готово. В следующем уроке мы запустим первое обучение агента 3DBall командой `mlagents-learn config/ppo/3DBall.yaml --run-id=first_run` и разберём, что происходит под капотом PPO.
